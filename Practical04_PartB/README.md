# Practical 4 — Part B: MiniBank

This folder contains only the Part B project work for Practical 4, based on the CEUE203 practical list.

## Compile and run
For Practicals 1–13:
```bash
javac MiniBankP4.java
java MiniBankP4
```

Practical 14 uses JUnit 5 imports for its test section; compile/run the application after removing the JUnit imports if using plain `javac`, or use the JUnit 5 dependency in an IDE/Maven project.
